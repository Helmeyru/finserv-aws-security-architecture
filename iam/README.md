# IAM Policy Examples

The flowlogs directory contains the IAM permissions policy and trust policy for sending FinServ VPC Flow Logs to CloudWatch Logs.

The AWS account ID 123456789012 is an example placeholder, not the actual deployment account.

Replace the example account ID, Region, and log group with values from your own AWS environment before deploying these policies.

These JSON files document the lab configuration and are not complete CloudFormation deployment templates.
